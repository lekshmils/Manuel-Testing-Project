# Manual Testing Project – Practice Software Testing (Tool Shop)

## Project Overview

This project focuses on manual testing of the Practice Software Testing (Tool Shop) web application. The objective is to verify application functionality, validate user workflows, identify defects, and document test execution results.

## Application Under Test

- **Application Name:** Practice Software Testing (Tool Shop)
- **Application URL:** https://practicesoftwaretesting.com/

## Testing Scope

The following modules are covered in this project:

- Search Module
- Sorting Module
- Filter Module
- Cart Module
- Category Module
- Checkout Module
- Language Module
- Payment Module
- End-to-End Testing
- Login Module

## Testing Activities

- Test planning
- Test case preparation
- Functional testing
- Positive and negative testing
- Test execution
- Expected and actual result comparison
- Defect identification and reporting
- Recording Pass/Fail status

## Testing Tools

- Google Chrome
- Microsoft Excel
- Google Drive
- GitHub
